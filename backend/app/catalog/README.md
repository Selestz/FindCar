# Справочник автомобилей

`data.json` — проверяемый снимок названий и ссылок открытых каталогов Drom и Auto.ru от 2026-09-07: 73 марки и 3 736 моделей/модельных семейств. Фотографий, объявлений, продавцов или контактных данных здесь нет.

Источники: <https://www.drom.ru/catalog/> и <https://auto.ru/catalog/cars/>; модели взяты из ссылок первого уровня на страницах соответствующих марок. Чтение было ограничено страницами справочника, с паузами между запросами. Навигационные разделы `engine`, `frame`, `photo` исключены.

`id` — внутреннее обозначение; `label` — подпись для пользователя; `sources` содержит конкретные обозначения для построения адреса на каждой площадке. По возможности внутренний id совпадает с Drom. Например: BMW `3-series` → Auto.ru `3er`, Mercedes-Benz → `mercedes`, Лада → `vaz`, Приора → `2170`, Mazda3 → `3`. Если модель имеется только в одном каталоге, вторая площадка для неё не предлагается. Обратное преобразование выполняется при нормализации объявлений.

Это справочник, а не обещание наличия объявлений или поддержки каждого региона. Он включает исторические модели. Для обновления нужно заново проверить страницы каталогов, исключить навигацию, сверить различающиеся обозначения и запустить тесты `test_catalog_visibility.py`. Снимок загружается один раз на процесс; для применения обновлённого JSON перезапустите API и worker.
