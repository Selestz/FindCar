# Phase 6 — доводка и проверка MVP

Дата: 2026-09-07. Реализация и проверки завершены. Из 20 пунктов DoD проверены 1–19 в предусмотренном спецификацией объёме, включая fixtures. Пункт 20 — фактический запуск через Docker Compose — первоначально был заблокирован локальной виртуализацией, затем проверен на Ubuntu VPS при публикации testerio.ru. Avito пропущен по просьбе пользователя; Drom и Auto.ru остаются подключёнными.

## Что изменено

- Ограничение тела запроса 64 KiB проверяется по фактически полученным байтам, включая запросы без Content-Length. Превышение возвращает 413 до обработки запроса приложением.
- Ответы API получили X-Request-ID, X-Frame-Options: DENY и Referrer-Policy: no-referrer. Сохранены запрет кеширования, nosniff, проверки Origin и CSRF.
- Диагностика worker содержит источник, job/run, попытку, причину запуска, версии парсеров и предупреждения. При исключении сохраняются класс, имя файла и строка; текст исключения с возможными паролями, SQL или содержимым страницы не выводится. Ошибки БД связываются с идентификатором запроса.
- В предложениях источников показан тип продавца: частное лицо, дилер или «тип не указан». Неизвестные данные не дополняются догадками.
- Форма создания поиска ждёт загрузки доступных источников: поздний ответ больше не меняет выбор пользователя. При выходе и переходах незавершённые запросы интерфейса отменяются.
- Миграция `0005_query_indexes` добавляет индексы для активных заданий источника, истории запусков, событий объявления и очереди проверки известных карточек.
- Добавлен инструмент создания согласованной резервной копии PostgreSQL и проверки восстановления: `python -m app.backup`. Команды — в [README](../README.md#резервная-копия-и-проверка-восстановления).

## Тесты и интерфейс

Полный прогон на отдельном PostgreSQL: **107 unit/integration-тестов прошли**, без пропусков интеграционных проверок. Ruff, mypy, pip check, frontend lint/typecheck и финальная production-сборка прошли. Два предупреждения Starlette о deprecated API не мешают тестам; это не аудит уязвимостей зависимостей.

Дополнительные тесты охватывают HttpOnly/SameSite/Secure cookie, смену и истечение сессии, отключённого пользователя, CSRF/Origin, ограничение тела запроса, небезопасные URL и содержимое изображений, диагностические данные без текста исключений, запрет перезаписи резервной копии и проверку её контрольной суммы.

На временном аккаунте через настоящий локальный API и Mock worker пройдены вход, создание поиска, получение выдачи, пауза расписания, сортировка, подробности, избранное, заметка после перезагрузки, скрытие/восстановление, отклонение дубля, прочтение событий, состояние источников, переход к основному содержимому с клавиатуры и выход. Проверены размеры 1505×1045 и 390×844: горизонтального переполнения нет, финальный сценарий прошёл без ошибок приложения. Найденные гонки начальной загрузки источников и выхода исправлены до повторного прогона. Временный аккаунт, его личные данные и файл пароля удалены; пользовательские поиски и решения сохранены.

## Миграции, производительность и восстановление

Миграция `0005_query_indexes` применена к рабочей БД; readiness подтверждает актуальную схему. На отдельной тестовой БД проверены полный downgrade/upgrade, повторный upgrade, откат до `0004_monitoring` и возврат на head. Alembic check не обнаружил расхождений модели и схемы. Эти разрушительные проверки не выполнялись на рабочей БД.

Локальная сравнительная проверка выдачи на 1000 синтетических автомобилях и 6000 событиях:

| Сортировка | До индексов, мс | После, мс |
|---|---:|---:|
| По времени обнаружения | 97,6 | 99,0 |
| Сначала дешевле | 65,5 | 63,0 |
| По снижению цены | 67,3 | 61,1 |

В этом объёме изменения небольшие; это диагностические замеры одного локального окружения, а не нагрузочный SLA. Новые индексы также обслуживают растущую очередь заданий и историю запусков. Финальная сборка интерфейса: JavaScript 243,42 kB (gzip 75,45 kB), CSS 16,20 kB (gzip 4,14 kB).

Две резервные копии рабочей БД созданы через pg_dump с экспортированным согласованным снимком и восстановлены в новые временные БД. Для финальной `.local/backups/phase6-final.dump` совпали контрольная сумма архива, состав **22 таблиц**, количество **139 строк** и хеши содержимого каждой таблицы. Временные БД после проверки удалены. При совпадении имени с существующей БД инструмент отказывается продолжать; восстановления поверх рабочей БД нет.

Архивы и `.dump.json` остаются в игнорируемой `.local/backups/`. Архив содержит приватные данные, включая аккаунты, сессии и заметки; он не зашифрован, поэтому хранить и передавать его следует как приватный файл. Для восстановления нужны оба файла и совместимые утилиты PostgreSQL. Проверен нативный PostgreSQL 17.11; Python-образ backend не содержит pg_dump/pg_restore.

## Оставшиеся ограничения

Avito остаётся отключённым по согласованному решению. Внешние уведомления, длительное нагрузочное испытание и оценка точности дедупликации на размеченной рыночной выборке не проводились. Существующие лимиты обхода площадок сохраняются. После развёртывания мониторинг выполняется на VPS независимо от локального компьютера.

## Дополнение: публикация на VPS

По запросу пользователя FindCar заменил HappyMarket на `https://testerio.ru/`; прежние контейнеры, БД и конфигурация Nginx сохранены для возврата. Созданы отдельные контейнеры и новая пустая база FindCar, локальные пользовательские данные не переносились. Настроены Secure cookie, единый HTTPS origin, перенаправление www/HTTP, перезапуск сервисов и ограничение размера журналов. Сертификат действует до 2026-11-29; существующий certbot.timer активен.

Полный прогон в контейнере выявил наследование COOKIE_SECURE из рабочей среды HTTP-тестами. Фикстура теперь явно задаёт false только для TestClient; отдельная проверка Secure cookie и настройки работающего сайта сохранены. После исправления **107 тестов прошли** на отдельной временной БД, которая удалена после прогона.

Публичный сайт проверен через Playwright/Edge (Browser plugin not available), размеры 1440×1000 и 390×844. Вход → временный Mock-поиск → результаты worker → подробности → сохранение заметки после перезагрузки → источники → выход прошли. Заголовок и содержимое страницы корректны, ошибок приложения/overlay/переполнения нет, Secure/HttpOnly cookie подтверждены. Тестовый аккаунт, его личные данные и неиспользуемые demo-объявления удалены; сохранённых поисков осталось 0. Реальные Drom/Auto.ru включены, но публичная браузерная проверка развёртывания использовала Mock и не подтверждает доступность площадок с IP VPS. Создан первоначальный PostgreSQL dump на сервере.
