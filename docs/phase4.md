# Phase 4 — реальные источники

Исторический отчёт Phase 4. Общие бюджеты, постоянное расписание и повторные попытки добавлены позднее в [Phase 5](phase5.md).

2026-09-07. Последовательно подключены **Drom и Auto.ru**. Рабочая часть Phase 4 готова; Avito остаётся неподключённым, поэтому полная интеграция всех трёх площадок не заявляется.

## Доступ и границы

Пользователь подтвердил разрешение на чтение публичных страниц. Реализованы обычные HTTP-запросы с идентификатором `FindCar/0.1`, без входа в аккаунты, cookies, приватных API или browser automation. Коды 401/403/429, страницы входа и ошибки структуры не превращаются в пустой список. Повторных сетевых попыток после блокировки нет; Retry-After соблюдается в процессе worker. Разрешены максимум два канонических перехода 301/308 с повторной проверкой того же HTTPS-хоста. Переход на авторизацию возвращает `AUTH_REQUIRED`.

Avito вернул HTML-оболочку каталога без объявлений. Доступный embedded JSON содержит настройки оболочки, а не результаты. Браузерная проверка публичной страницы отклонена site-safety policy инструмента до запроса пользовательского подтверждения; обход не выполнялся. Avito остаётся `ACCESS_NOT_CONFIGURED`. Потребуется доступный проверяемый HTML/JSON-контракт либо возможность проверить разрешённый механизм в подходящем окружении. Это ограничение не препятствует Drom и Auto.ru.

## Реализация

Каждый источник имеет собственные adapter, transport, parser и normalizer. Общий HTML reader строит ограниченное дерево, не исполняя скрипты. Drom использует JSON-LD `Car` и семантические `data-ftid`; Auto.ru — JSON-LD `Product/Offer` и префиксы классов карточек. Хешированные суффиксы CSS-классов Auto.ru не зафиксированы в parser. Неизвестная структура возвращает `PARSER_ERROR`; явная пустая выдача проверяется отдельно.

Марка и модель обязательны, чтобы не обходить общий каталог. Drom переводит марку, модель, цену и выбранный поддерживаемый город; Auto.ru также переводит диапазон лет. Остальные условия проверяются локально либо остаются непроверенными. Drom поддерживает Москву, Санкт-Петербург и Новосибирск, Auto.ru — Москву. Пустой регион означает всю Россию. Радиус и каноническое поколение пока не подтверждаются; «1 поколение» не приравнивается к коду производителя. «4 и более владельцев» хранится как неизвестное число. Auto.ru RUR приводится к RUB; другие валюты не конвертируются.

На источник за задание: до 2 страниц, 40 результатов и 3 detail-запросов для потенциальных совпадений. Между HTML-запросами — не менее 1,5 секунды. HTML ограничен 2 МБ, чтение одного ответа — 12 секундами, общий сбор — настройкой `JOB_TIMEOUT_SECONDS` (локально 90). После частичного сбоя уже полученные объявления сохраняются, run показывает partial и причину. Пустая выдача или HTTP 404 не снимают прежние объявления. Статусы `SoldOut/OutOfStock` в подробной карточке — явное основание `REMOVED`; неизвестное значение остаётся `UNKNOWN`.

Адреса фотографий хранятся новой миграцией `0003_source_images`. `GET /api/listings/{id}/image/{index}` проверяет сессию и принадлежность автомобиля пользователю. Хосты ограничены `s31.auto.drom.ru`, `photo.auto.ru`, `avatars.avto.ru`, также проверяются путь и формат адреса. Перенаправления изображений запрещены. Загружается до 2 МБ; принимаются только JPEG/PNG/WebP, до 16 млн пикселей. Превью пересоздаётся в JPEG до 1000×800 без исходных EXIF. Кэш в памяти процесса: до 64 изображений, TTL 24 часа; ответ браузеру приватный. Недоступная фотография не скрывает автомобиль.

Для pHash используются реальные, а не синтетические байты. Разные размеры одной фотографии считаются одним изображением. На задание обработка ограничена шестью фотографиями: максимум по три у двух автомобилей. При меньшем числе снимков нет автоматической склейки по фотографиям; действуют ручная проверка и правила Phase 2. Для остальных машин/изображений доступно превью по запросу интерфейса. Общие бюджеты между несколькими worker-процессами и постоянный scheduler остаются Phase 5; текущая конфигурация предполагает один worker.

## Интерфейс и запуск

Форма поиска содержит выбор площадок. Реальные и демонстрационные источники обозначены отдельно. Смена набора источников повышает версию условий и убирает старую выдачу этого поиска до обновления. Старые избранное, заметки и сохранённый демо-поиск не удаляются. Карточки показывают фотографии, реальные ссылки и корректный source status.

Настройки: `DROM_ENABLED=true`, `AUTO_RU_ENABLED=true`, `JOB_TIMEOUT_SECONDS=90`; по умолчанию в примере live-источники выключены. Затем `alembic upgrade head` и перезапуск API/worker. Настройки передаются и через Docker Compose. На этой машине миграция применена и сервисы запущены локально; аппаратная виртуализация Docker по-прежнему недоступна.

## Проверки и фактический результат

- 78 unit/integration-тестов на отдельной PostgreSQL БД: нормализация, неизвестные поля, RUR, пустой ответ против ошибки, вход/429/503, канонические переходы, ограничения адресов и размера, безопасное преобразование фото, владение фотографиями, выбор источников, partial ingestion и прежние сценарии Phase 1–3.
- Обезличенные минимальные контрактные fixtures находятся в `backend/tests/fixtures/drom` и `auto_ru`. README рядом описывает происхождение и синтетические замены; полные исходные HTML, контакты и авторы фото в fixtures не включены.
- Ruff/mypy, TypeScript/ESLint и production build; Alembic check подтверждает соответствие схемы.
- Проверены реальные пустые поиски с ценой до 1 ₽ у Drom и Auto.ru. Auto.ru в этом случае передаёт Product без offers и карусель похожих предложений; рекомендации не импортируются. Неизвестная структура по-прежнему считается ошибкой.
- Через браузер проверены выбор двух площадок, создание поиска, обновление, непроверенные результаты, карточка и загрузка фотографии Auto.ru. Desktop 1505×1045 и mobile 390×844: горизонтального переполнения нет. Событие снятия объявления отображается без ложной стрелки изменения цены.
- Реальные HTTP 200 для поиска и detail обоих источников. Сквозной поиск «Panamera · Drom и Auto.ru» создан через интерфейс с условиями Москва, 2010–2015, до 1,9 млн ₽, до 5 владельцев. Получены по одной карточке: Auto.ru — подтверждённое совпадение; Drom — непроверенное число владельцев, при этом detail сообщает `OutOfStock`. При итоговом обновлении в 08:57 МСК фотографии Auto.ru и Drom успешно загружены и отображены. Страница источников показывает оба источника доступными.

Адрес сохранённого локального поиска: `http://localhost:8080/?search=42cbb2d5-093c-4fd4-9f14-24979379ce94`. Результаты отражают только ограниченную проверку на указанную дату; они не гарантируют полноту рынка или постоянную доступность площадок.
