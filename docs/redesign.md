# Редизайн C и исправления поиска

Пользователь утвердил тёмный вариант C с фиолетовым акцентом и публикацию всех исправлений вместе.

## Поведение

В результатах и коллекциях остаются только `ACTIVE`. В смешанной группе учитываются активные предложения и их цены; снятые доступны в истории и по переключателю в подробностях. Drom явно распознаёт `bull_sold`, `SoldOut`, `OutOfStock`; каталог не может отменить подтверждённое снятие. Ошибка чтения не равна снятию.

Mock отключён по умолчанию и принудительно выключен для рабочих Compose-сервисов. Старые demo-поиски и объявления исключены из API списков, карточек, изображений, событий и проверки дублей. Они не удаляются из базы вместе с личными заметками. Тесты явно включают fixtures в отдельной базе `_test`.

Название автоматически составляется из марки, модели, года, бюджета и региона; старое поле `name` принимается для совместимости и игнорируется. Новый `POST /api/searches?start=false` сохраняет условия без немедленного запроса, с последующим обновлением по расписанию. Без параметра поиск запускается сразу, как прежде.

Справочник отдаётся аутентифицированными `/api/catalog` и `/api/catalog/{make}`. Отдельные обозначения площадок решают различия BMW 3-Series/3er, Mercedes-Benz/mercedes, Лада/vaz, Приора/2170, Mazda3/3. Источник, где выбранная модель отсутствует, отключён в форме. Проверка моделей выполняется также на сервере.

Годы: 1886–следующий год. Цены: 100 000–100 000 000 ₽ с шагом 100 000 и вариант без ограничения; поиск по списку доступен с клавиатуры. Дополнительные фильтры сохранены, поколение сбрасывается при смене модели.

## Проверки

Проверены сборка, типы, lint; интеграционные тесты PostgreSQL покрывают исключение demo и снятых предложений, сохранение истории, сохранение поиска без запуска, автоматические названия, отображение текущей цены смешанной группы и защиту от возврата снятых объявлений из устаревшего каталога.

Браузерная проверка выполнена в Edge/Playwright на 1536×1024 и 390×844, на отдельном локальном пользователе с реальными объявлениями Drom: выбор BMW и модели, годы и бюджет, сохранение и перезагрузка, избранное, заметки, скрытие/возврат, мобильные списки, Escape, переход фокуса, источники и события. Нет ошибок выполнения, ответов 4xx/5xx после входа, пустого приложения, отладочного overlay или горизонтального переполнения.

Источники по-прежнему проверяются в пределах первых страниц и бюджета подробностей. Наличие модели в справочнике не гарантирует активные предложения. Производственная база сохраняется при обновлении; новой миграции схемы нет, head остаётся `0005_query_indexes`.
