# Phase 3 — Frontend MVP

Завершена 2026-09-06. Интерфейс работает с существующими API, PostgreSQL и worker. Финальная production-сборка прошла, локальный API перезапущен с последними исправлениями и возвращает `ready`. Реальные площадки подключаются в Phase 4; текущие объявления синтетические, изображения автомобилей — подписанные иллюстрации.

## Пользовательские сценарии

- Главная страница содержит форму поиска и последние изменения. Дополнительные характеристики раскрываются отдельно; диапазоны проверяются до сохранения. Неизвестные значения не подменяются нулями. Поиск по радиусу явно обозначен как пока неподдерживаемый.
- Сохранённые поиски доступны в навигации. Можно изменить условия, переименовать, обновить и удалить поиск с подтверждением. Переименование не сбрасывает актуальную выдачу. Удаление во время выполняющегося или ожидающего задания возвращает понятный конфликт; после завершения доступно снова.
- Одна строка результата представляет один персональный VehicleCluster. Показаны источники, число объявлений, диапазон цен, характеристики, время обнаружения, изменения цены и цитаты из описания. Доступны шесть сортировок и вкладки «Все», «Новые», «Избранное», «Скрытые», «Изменившиеся».
- Подробности открываются по постоянному адресу. Внутри — полные характеристики, предложения каждого источника, описания, график и список наблюдений цены, заметки, основания объединения и ручные решения. Демонстрационные URL не представлены как рабочие ссылки на площадки.
- Личные заметки можно добавлять, редактировать и удалять. Избранное и скрытие сохраняются после перезагрузки; скрытую машину можно восстановить. Удаление поиска не удаляет личное состояние автомобиля.
- Страница проверки дублей сравнивает два объявления рядом и позволяет подтвердить или отклонить объединение. В подробностях доступно разделение; правила сохранения состояния и приоритета ручных решений остаются из Phase 2.
- Лента изменений поддерживает фильтр непрочитанных, отметку отдельных/показанных событий и загрузку следующих страниц. Страница источников показывает доступность, последнюю успешную проверку, ошибки и состояние worker.

## Маршруты

| Адрес | Содержание |
| --- | --- |
| `/` | Поиск и последние изменения |
| `/?search=UUID` | Сохранённый поиск и выдача |
| `/search/new` | Новый сохранённый поиск |
| `/vehicles/UUID` | Подробности автомобиля |
| `/favourites`, `/hidden` | Личные подборки |
| `/duplicates` | Проверка возможных дублей |
| `/events` | Лента изменений |
| `/sources` | Состояние источников |

Навигация использует History API, поддерживает прямые адреса и кнопку «Назад». Интерфейс имеет видимый фокус, подписи элементов и ссылку перехода к основному содержимому с клавиатуры.

## API и правила данных

- `GET /api/vehicles`: необязательный `search_id`, `include_unverified`, `view=all|new|favourites|hidden|changed`, `sort=found|newest|price_asc|price_desc|mileage|price_drop`, `after` и `limit`. Сортировка выполняется в PostgreSQL до пагинации. Неизвестные цены/пробег/даты идут последними. Цены и их сравнение пока ограничены RUB; конвертации валют нет.
- Диапазон цены и минимальный пробег считаются по активным предложениям кластера, если они есть. Иначе используются исторические предложения. Неизвестная цена активного объявления не подменяется старой ценой снятого. В выдаче поиска агрегируются только входящие в текущие условия объявления; общий состав доступен в подробностях.
- «Новые» и «Изменившиеся» опираются на непрочитанные события пользователя; сортировка снижения цены — на время соответствующего события. Обычная выдача исключает скрытые автомобили. Подборки без `search_id` доступны независимо от существования поисков.
- Курсор содержит идентификатор кластера, позиция определяется в текущем порядке выдачи. Это не замороженный снимок: изменения данных могут менять порядок между страницами. Исчезнувший/неподходящий курсор даёт 409 и требует загрузки заново; клиент исключает повторные карточки.
- `PATCH /api/vehicles/{id}/state`: текущая `version` и `favourite`, `hidden` или новая `note`. `PATCH /api/vehicles/{id}/notes/{note_id}`: `version`, `text`; `null` удаляет заметку. Применяются проверка владельца, CSRF, блокировка пользователя и контроль версии; устаревшая версия даёт 409. Заметки после разделения сохраняют происхождение, вложенные записи тоже редактируются.
- `GET /api/events`: `unread`, `after`, `limit`, число непрочитанных и следующий курсор. `POST /api/events/read` принимает до 100 идентификаторов; повторная отметка идемпотентна. Чужие идентификаторы отклоняются атомарно.
- `GET /api/duplicates` работает и без поиска; ответ дополнен полями для сравнения. Подробности автомобиля включают личное состояние. Миграция Phase 3 не требуется: используются существующие колонки Phase 2.

Текст продавца выводится как текст React, без вставки HTML. Подсветка слов вроде «есть окрасы» или «расход масла» обозначает цитату продавца и не является выводом о техническом состоянии.

## Проверки

- 53 unit/integration-теста прошли на настоящем PostgreSQL, в отдельной БД `findcar_test`. Новые тесты покрывают личное состояние, заметки, конфликты версий, CSRF и изоляцию пользователей, прочтение событий, сортировку/пагинацию, сохранение данных после удаления поиска, активные цены и переименование.
- Backend: Ruff, mypy и Alembic check без новых операций. Frontend: ESLint, TypeScript, проверка форматирования и production build прошли на окончательном коде. После подтверждённого повторного запуска прежний тайм-аут автоматической проверки разрешений устранён.
- В Codex IAB на работающем сервере проверены избранное, скрытие/восстановление, подробности и создание/редактирование/удаление заметки с перезагрузкой. Временные заметки и изменения личного состояния после проверки отменены.
- Playwright с установленным Edge проверил сортировку реальной локальной выдачи, мобильную навигацию источников, пустое состояние, переход клавиатурой, проверку диапазонов и создание/удаление временного поиска. На контролируемых ответах дополнительно проверены сравнение дублей, безопасное отображение HTML-подобного описания и частичная выдача. Эти ответы не являются результатом работы реальных источников.
- Визуально проверены 1505×1045 и 390×844, карточки, подробности и сравнение. Горизонтального переполнения и ошибок приложения в консоли не обнаружено.

Docker-контейнеры на этой машине не запускались из-за недоступной аппаратной виртуализации; используются локальные PostgreSQL/API/worker/Vite. Автоматический мониторинг и работа с реальными изображениями площадок остаются будущими этапами. Ручное обновление по-прежнему соблюдает серверный cooldown.

Финальная проверка после перезапуска: `/api/ready` вернул `ready`; в Codex IAB открыты лента изменений и сохранённый поиск. Сортировка «Сначала дешевле» поставила Panamera 4S за 1 790 000 ₽ первой среди трёх автомобилей; предупреждений и ошибок приложения в консоли нет. Последние исправления приоритета активной цены, переименования поиска и запрета удаления поиска с активным заданием применены к работающему API и покрыты успешными backend-тестами.
